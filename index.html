01 / Featured work

From numerical contract
to verified RTL.

ADC-aware adaptive BFP FFT
for FMCW radar

A synthesizable 1024-point radix-2 FFT using stage-wise magnitude monitoring and guard-based scaling. The work balances numerical precision, overflow behavior, FPGA timing, and memory/resource cost.

My contribution spans SystemVerilog RTL, a bit-accurate Python golden model, regression comparison, and implementation analysis on Intel Cyclone V.

SystemVerilog / Python / ModelSim / Quartus Prime

Functional agreement120 multi-length Python ↔ RTL regressions; bit-exact agreement.
