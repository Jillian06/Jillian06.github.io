C++17 · LEARNING PROJECT · COMPILER MIDDLE END

Mini IR Optimizer

An independently developed, deliberately small compiler exercise. Parses assignment programs into a typed instruction representation, propagates and folds constants, uses backward liveness to remove unused assignments, and checks the optimized program with a reference interpreter and regression tests.

Source assignments → Parse / validate → three-address-style IR → Constant propagation & folding → Backward liveness → dead assignment elimination → Interpret original vs optimized output
