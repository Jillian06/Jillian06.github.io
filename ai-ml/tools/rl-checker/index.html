Electrical R–L Sanity Checker

A small browser tool for physically grounded engineering calculations. Change the inputs to compute the ideal series R–L response under sinusoidal steady-state RMS excitation. Invalid inputs and user-defined current limits are checked explicitly.

Scope: Demonstrates circuit equations, usability, input validation and clear warnings. This is not an ML application, a transformer/air-core reactor design program, a thermal model, or a substitute for engineering review.

3 / Equations and engineering reasoning

ω = 2πf; XL = ωL; |Z| = √(R² + XL²); I = V / |Z|

P = I²R; Q = I²XL; |S| = VI; PF = R / |Z|. Voltages across R and L are 90° apart; therefore V ≈ √(VR² + VL²) is a useful independent numerical consistency check.

Assumptions: fixed ideal linear R and L; sinusoidal steady-state RMS supply; no saturation, winding skin/proximity losses, parasitic capacitance, core effects, temperature rise, insulation limits or transient behavior. The tool does not determine regulatory compliance. The current limit is purely user-specified. No data is saved or sent to a server.

Suggested test cases: R = 0 and L > 0 → P = 0; L = 0 and R > 0 → power factor 1; R = 0 and L = 0 → zero-impedance case must be rejected, not reported as a finite current.
